# Treasure Hunter

Treasure Hunter adalah game platformer 2D yang dibuat menggunakan Godot 4.5.

## Tujuan
Belajar membuat game 2D dari nol menggunakan Godot.

## Engine
- Godot 4.5
- GDScript
